# Architecture Decision Records

Append-only. One file per decision: `ADR-<n>-<slug>.md`. Never delete or silently edit a past ADR — if a decision changes, add a new ADR that supersedes it and say so explicitly.

Use this whenever a spec file in `specs/` is ambiguous, missing a needed schema/field, or conflicts with `00-ARCHITECTURE.md`. See `AGENT_INSTRUCTIONS.md` for the required ADR format.
