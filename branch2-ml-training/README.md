# Branch 2: ML/DL Model Training Template (RTX 5060 Laptop)

## Overview
This branch provides a machine learning/dynamic learning model training template designed to run on the RTX 5060 laptop (outside the homeserver network). The template trains on attack types generated by the target website and can receive training data via the admin dashboard's "send template" feature.

## Architecture
- **Training Script**: `train_classifier.py` - Main training pipeline
- **Inference Server**: `inference_server.py` - Flask/FastAPI server with `activation_snapshot`
- **Feature Extraction**: Uses same `feature_names.json` as the main project
- **Data Receiver**: HTTP endpoint to receive events from dashboard "send template"
- **Evaluation**: Offline evaluation on held-out test split

## MongoDB/PostgreSQL Connection
Training data can be loaded from either:
- PostgreSQL (primary): `postgresql://postgres:postgres@postgres.data-layer.svc.cluster.local:5432/sentinel`
- MongoDB placeholder (alternative): `mongodb://admin:password@mongo-service.data-layer.svc.cluster.local:27017/sentinel_lab`

Replace connection strings with actual values when the user shares the MongoDB URI.

## Key Features
1. Trains on CICIDS2017 + lab-generated attack traffic
2. Maps dataset attack types to `predicted_class` enum
3. Includes `activation_snapshot` in inference responses (mandatory per specs)
4. Saves model artifacts for later inference
5. Provides `/predict` endpoint compatible with `fusion` module
6. Exports training metrics for dashboard

## Deployment (for RTX 5060 laptop)
```bash
# Clone this branch and run
python scripts/train_classifier.py --data-source postgres --epochs 10

# Start inference server
python api/inference_server.py

# The server will be available at http://localhost:8000
# POST /predict to get predictions with activation_snapshot
```

## Data Flow
1. Admin dashboard collects events from PostgreSQL
2. User clicks "send template" to forward events to laptop
3. Laptop receives events via HTTP POST `/receive-training-data`
4. Training script processes events and trains classifier
5. New model weights are saved and can be loaded by inference server
6. Fusion module calls `/predict` for classifications
